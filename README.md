# 🐍 Python DSA

A beginner-friendly repository for learning **Python** and **Data Structures & Algorithms (DSA)**. This repository contains Python programs, coding exercises, and practice problems to strengthen programming fundamentals and problem-solving skills.

---

## 📚 Topics Covered

- Python Basics
- Variables and Data Types
- Input & Output
- Escape Characters
- Strings
- Lists
- Dictionaries
- Functions
- *args and **kwargs
- Default Function Arguments
- Conditional Statements
- Loops
- Basic Object-Oriented Programming (OOP)
- Dynamic Typing
- String Manipulation
- Sum of Numbers Program
- Odd & Even Number Checker

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Afrid-40/python_dsa.git
```

2. Open the project

```bash
cd python_dsa
```

3. Run the Python file

```bash
python main.py
```
