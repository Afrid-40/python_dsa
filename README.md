## 🚀 Sample Concepts

### Exception Handling

```python
try:
    x = int(input())
    y = int(input())
    print(x / y)
except ZeroDivisionError:
    print("Cannot divide by zero")
except ValueError:
    print("Invalid Input")
```

---

### OOP Example

```python
class Person:
    def __init__(self, name):
        self.name = name

    def display(self):
```
